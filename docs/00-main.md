# RAG Chatbot 開發主檔

> 專案的**單一入口**：目前狀態、決策紀錄、各文件連結。

## 1. 專案目標

以自有文件為知識來源的 RAG 問答系統。目前的用途是**示範用的介紹/推薦自動回覆**：訪客透過 LINE 詢問「我自己（或自訂人物）」與「我參與開發的產品」，系統依文件內容回答並適度推薦。

同一套系統以「**情境**」切換用途：換一組文件與設定，即可支援其他問答（例如日後的個人知識助理），不需修改程式。

| 階段 | 目標 | 狀態 |
|---|---|---|
| 第一階段 | 筆電本機版：文件集與情境、匯入文件、RAG 回答、顯示依據、對話紀錄、管理介面（Prompt 調整與重測） | 🔄 核心完成（M3）；管理介面待 M5 |
| 第二階段 | LINE 官方帳號串接，透過 HTTPS 通道把 Webhook 轉到筆電，供訪客用手機詢問 | ✅ M4 完成 |

## 3. 開發流程

1. **文件先行**：需求、設計寫進文件 → 使用者確認 → 才開始寫程式。
2. **完成的定義**：程式撰寫完成 **且** 單元測試全部通過。
3. **功能測試**：每個里程碑結束時，依 [04-testing.md](04-testing.md) 執行並記錄結果。
4. **文件只寫現況**：過時內容直接刪除，不保留刪除線；方向改變時在「決策紀錄」新增一列摘要。舊版本內容由 Git 保存。
