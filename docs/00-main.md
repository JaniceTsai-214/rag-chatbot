# RAG Chatbot 開發主檔

> 專案的**單一入口**：目前狀態、決策紀錄、各文件連結。

## 1. 專案目標

個人用的文件問答機器人（非客服、非訂單處理）。

| 階段 | 目標 | 狀態 |
|---|---|---|
| 第一階段 | 筆電本機版：聊天介面 + 匯入文件 + RAG 回答 + 顯示依據 + 對話紀錄 + Prompt 調整與重測 | 🔄 開發中（M2 規劃中） |
| 第二階段 | 接上 LINE Messaging API，透過 HTTPS 通道把 Webhook 轉到筆電 | ⏸ 尚未開始 |

## 3. 開發流程

1. **文件先行**：需求、設計寫進文件 → 使用者確認 → 才開始寫程式。
2. **完成的定義**：程式撰寫完成 **且** 單元測試全部通過。
3. **功能測試**：每個里程碑結束時，依 [04-testing.md](04-testing.md) 執行並記錄結果。
4. **文件只寫現況**：過時內容直接刪除，不保留刪除線；方向改變時在「決策紀錄」新增一列摘要。舊版本內容由 Git 保存。
