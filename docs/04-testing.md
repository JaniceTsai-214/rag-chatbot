## 1. 單元測試規範

- 框架：`pytest` + `pytest-cov`。
- **完成的定義**：功能程式寫完，且 `pytest` 全部通過，才算完成。
- 覆蓋率目標：`src/rag_chatbot/` 核心模組 ≥ 80%（`app.py` 介面層不計）。
- **單元測試不依賴 Ollama**：使用 `tests/fakes.py` 的 `FakeEmbedder`（以關鍵字產生固定向量）與 `FakeLLM`（回傳可預期的文字）。
- 需要真實 Ollama 的測試標記 `@pytest.mark.ollama`，預設略過，用 `pytest -m ollama` 才執行。
- 資料庫使用暫存檔（`tmp_path`），測試之間互不影響。

### 各模組測試重點

| 模組 | 測試重點 |
|---|---|
| loaders | 各格式能擷取文字；PDF 頁碼正確；MD/DOCX 標題正確；FAQ 每列一筆；空檔/壞檔有明確錯誤 |
| chunker | 長度上限、重疊、在句號/段落斷開、短文不切 |
| vector_store | 新增/刪除/搜尋；相似度排序正確 |
| ingest | 新檔匯入；相同 hash 跳過；修改後取代舊段落；刪除文件 |
| retriever | top_k、門檻過濾、全部低於門檻時回傳空 |
| prompts | 新增版本、切換啟用版本、取得指定版本 |
| history | 建立對話、寫入/讀取訊息、重跑關聯 |
| rag | 正常回答帶 sources；無相關段落時拒答且**不呼叫 LLM**；Prompt 組裝內容正確；多輪查詢組合 |
| eval | 讀題集、計算命中預期來源、輸出報告 |

## 2. 功能測試方法

### 2.1 測試資料
在 `tests/functional/` 準備一組**虛構但具體**的個人文件，內容含明確數字，方便判斷回答是否正確：

| 檔案 | 內容（虛構） |
|---|---|
| `洗衣機使用手冊.pdf`（3 頁） | 第 2 頁：保固 2 年；第 3 頁：濾網每月清潔一次 |
| `居家安全守則.docx` | 標題「用電安全」「火災應變」各一節 |
| `讀書筆記.md` | 兩本書的筆記，各有 `##` 標題 |
| `個人FAQ.csv` | 5 筆問答（例如「健保卡遺失怎麼補辦？」） |

### 2.2 執行方式
1. 刪除 `data/app.db`，從乾淨狀態開始。
2. 啟動 `streamlit run app.py`，依下表逐項操作。
3. 將結果填入第 4 節「執行紀錄」：通過 / 不通過 / 備註（含回答時間）。

### 2.3 判定原則
- **正確**：回答內容與文件一致，且回答依據指向正確檔案/頁碼。
- **拒答正確**：文件中沒有的問題，回覆找不到，不編造。
- **編造（嚴重缺陷）**：回答中出現文件沒有的事實。

## 3. 功能測試案例

| 編號 | 里程碑 | 案例 | 步驟 | 預期結果 |
|---|---|---|---|---|
| FT-01 | M2 | 匯入四種格式 | 上傳 PDF、DOCX、MD、CSV 各一 | 文件列表出現 4 筆，段落數 > 0 |
| FT-02 | M2 | 重複匯入 | 再次上傳同一 PDF | 不新增段落，提示「已是最新」 |
| FT-03 | M2 | 修改後匯入 | 修改 MD 內容後上傳 | 舊段落被取代，搜尋得到新內容 |
| FT-04 | M2 | 刪除文件 | 刪除 DOCX | 列表移除；之後問 DOCX 內容會拒答 |
| FT-05 | M3 | 事實型問題 | 問「洗衣機保固幾年？」 | 答「2 年」，依據顯示使用手冊 PDF 第 2 頁 |
| FT-06 | M3 | FAQ 命中 | 以不同說法問 FAQ 中的題目（如「健保卡掉了要怎麼辦」） | 回答與 FAQ 答案一致，依據含 FAQ |
| FT-07 | M3 | 文件外問題 | 問「明天台北天氣如何？」 | 回覆固定拒答文字，無依據，不編造 |
| FT-08 | M3 | 跨文件問題 | 問「洗衣機和用電安全要注意什麼？」 | 回答整合兩者，依據含兩個來源 |
| FT-09 | M4 | 顯示依據 | 展開某回答的「回答依據」 | 顯示檔名、頁碼/標題、分數、原文 |
| FT-10 | M4 | 多輪追問 | 先問「洗衣機保固幾年？」，再問「那濾網多久清一次？」 | 回答洗衣機濾網每月清潔一次 |
| FT-11 | M4 | 對話紀錄保存 | 關閉並重開程式 | 先前對話仍在、可點開 |
| FT-12 | M4 | 修改 Prompt | 將 Prompt 改為「以英文回答」並儲存 | 版本號 +1；新問題以英文回答 |
| FT-13 | M4 | 重新測試 | 對 FT-05 的問題按「用目前 Prompt 重跑」 | 新舊回答並排，標示各自 Prompt 版本 |
| FT-14 | M5 | 批次評估 | 執行 `eval questions.csv` | 產出報告，含每題回答、依據、是否命中預期來源、耗時 |
| FT-15 | 全部 | 效能 | 記錄 FT-05～FT-08 回答時間 | 3B 模型 ≤ 60 秒 |
